# 桌宠 UI 交互方案 v0.1

> 状态：草案，待评审
> 关联协议：`desktop-v1`（`jinyu-memory/docs/protocol/desktop-v1.md`）
> 形态：Windows 优先，透明无边框置顶窗口 + 托盘

## 0. 设计原则

- **是宠物，不是聊天软件**：没有常驻聊天窗口、没有历史记录页；对话是「召唤出来、说完就收起」的
- **不挡桌面**：默认只有角色本体和正在显示的气泡可点，其余区域全部穿透
- **不抢焦点**：只有输入胶囊展开时才借用前台焦点，关闭立即归还
- **打扰分级**：日常反应不弹窗、不出声；只有优先级 3 的提醒可以打断
- **服务端只给语义**：情绪、动作意图、气泡文本；节奏和片段由客户端自己决定

## 1. 形态与布局

| 项 | 规格 |
|---|---|
| 窗口 | 透明、无边框、不进任务栏、置顶（全屏应用时让位） |
| 默认尺寸 | 角色高 180px，按比例缩放；可调 50%–200% |
| 默认位置 | 主屏工作区右下角，右边距 24px、底边距 24px（任务栏之上） |
| 锚点记忆 | 按显示器 ID 保存位置与缩放；显示器断开回主屏 |
| 气泡 | 角色头顶上方 12px，最大宽 280px；顶部空间不足翻到脚下；左右夹取 16px |
| 输入胶囊 | 展开后宽 320px、高 40px，位于气泡位置 |
| 菜单 | 220px 宽圆角面板，贴角色一侧展开，自动避让屏幕边缘 |
| 阴影 | 角色脚下的椭圆软阴影，**不进入命中区域** |

```
                    ╭──────────────────╮
                    │  你回来啦。        │   ← 气泡（可点/可复制）
                    ╰────────┬─────────╯
                       ╭─────┴─────╮
                       │  ◕     ◕  │      ← 角色（唯一常驻命中区）
                       │    ﹏      │
                       ╰──┬─────┬──╯
                          （阴影）
     ┌─────────────────────────────┐
     │ 和瑾瑜说点什么…        🎤 ➤ │      ← 输入胶囊（Esc 收起）
     └─────────────────────────────┘
```

## 2. 命中区域与穿透

窗口 Region 由以下矩形并集构成，随时机变化：

| 时机 | Region 组成 |
|---|---|
| 静置 | 角色 alpha 包围盒 + 6px 内边距（不含阴影） |
| 气泡显示 | 角色包围盒 + 气泡矩形 |
| 输入胶囊展开 | 角色包围盒 + 胶囊矩形 |
| 菜单展开 | 角色包围盒 + 菜单矩形 |
| 拖拽中 | 角色包围盒；鼠标按下时 `SetCapture`，松手释放 |

规则：

- 空闲时**绝不**让 Region 覆盖整屏，避免出现"看不见却点不动"的死区
- Region 随气泡尺寸变化重算，频率上限 8Hz；只在包围盒实际变化时更新
- 悬停眼神跟随需要全局光标位置：用 150ms 轮询 `GetCursorPos`，不开全局鼠标钩子
- 系统空闲判断用 `GetLastInputInfo`，同样不开钩子

## 3. 输入语法

### 3.1 鼠标

| 动作 | 判定 | 本地反馈 | 上行事件 |
|---|---|---|---|
| 单击 | <250ms 且位移 <4px | 挤压一下 + 随机本地台词（30% 概率） | `event.interaction(kind=poke)` |
| 双击 | 两次间隔 <300ms | 戳一下并展开输入胶囊 | 同上，另加本地 UI |
| 长按头部 600ms | 头部区 = 包围盒上 1/3 | 摸头动作 + 眯眼 | `event.interaction(kind=pet)` |
| 按住拖动 | 位移 >4px | 跟随鼠标，轻微摆动 | 松手后 `kind=drag` |
| 快速甩出 | 松手速度 > 阈值 | 翻滚 + 落地弹跳 | `kind=throw` |
| 右键 | `contextmenu` | 展开菜单 | 无 |
| Ctrl+滚轮 | 每格 10% | 缩放并保存 | 无 |

单击立即触发、不等待双击判定，避免"点了没反应"。

### 3.2 键盘

| 快捷键 | 行为 |
|---|---|
| `Ctrl+Alt+J` | 展开/收起输入胶囊（可配置，首次启动检测冲突） |
| `Enter` | 发送 |
| `Shift+Enter` | 换行 |
| `Esc` | 收起胶囊/菜单，**把焦点还给原应用** |
| `1`–`4` | 预留：未来选项气泡 |

焦点借用流程：展开前记录 `GetForegroundWindow()`，去掉窗口 `WS_EX_NOACTIVATE` 并激活；收起时恢复 `WS_EX_NOACTIVATE` 并把焦点还给原窗口。**任何情况下不允许窗口长期占据前台焦点。**

### 3.3 托盘

显示/隐藏、锁定穿透（玩游戏时用）、勿扰、设置、连接状态、退出。双击托盘切换显示；单实例锁，重复启动只唤起设置窗口。

## 4. 气泡系统

- 同一时间只显示一个气泡；一条 `pet.say` 内的多个气泡按 `delay_ms` 依次出现
- 打字机 25ms/字，单条最长 1.2s 完成；尊重系统「减少动态效果」设置
- 自动消失 = 4s + 50ms/字，夹在 5–12s；鼠标悬停暂停；单击固定 30s，再点关闭
- 超过 4 行折叠，单击展开；右键复制文本，本地提示「已复制」1.5s
- 队列：跨消息最多排队 2 条；`priority=3` 插队，其余按到达顺序
- `recall` 在 120s 内到达时淡出消失；超时不处理
- 优先级：`3` 提醒（可打断、可出声、可穿透全屏隐藏）、`1` 普通对话、`0` 氛围台词（不出声）

## 5. 输入胶囊

- 收起态不占桌面；悬停角色时头顶右侧浮出 24px 的「…」小钮，点击也可展开
- 占位文案「和瑾瑜说点什么…」；最多 500 字，480 字起显示计数
- 发送后立即收起，头顶出现三点「思考中」；20s 无回复则转离线态，不伪造回复
- 发送失败：胶囊自动重新展开并保留原文，气泡提示「没送出去」
- 麦克风按钮：按住说话，松开转文字；有本地 ASR 时只发文本，否则上传一次性音频 URL
- 点击胶囊外部或 Esc 收起；IME 候选窗由 WebView2 原生处理

## 6. 右键菜单与设置

菜单项（一级，唯一二级是「形象」）：

```
形象与服装   >  缩略图网格（whale / 其它形象包）
静音 / 勿扰     30 分钟 · 1 小时 · 今天
隐藏            10 分钟 · 今天
连接状态        （只读：已连接 / 重连中 / 未配对）
设置
退出
```

设置是**独立普通窗口**（不透明、有边框），包含：设备配对/解除、缩放、置顶、全屏时隐藏、声音与音量、开机自启、全局热键、动画包管理、日志导出。

## 7. 状态机与动画映射

| 状态 | 进入 | 表现 | 可被打断 |
|---|---|---|---|
| idle | 默认 | 循环闲时动作，30–90s 随机切换 | 全部 |
| attention | 光标进入 300px 内 | 头部转向光标，3s 后回 idle | 全部 |
| think | 已发送消息 | 头顶三点，最长 20s | 回复、离线 |
| talk | `pet.say` | 气泡 + 说话动作 | 拖拽、提醒 |
| react | poke/pet/feed | 600–1200ms 局部反应 | 拖拽、提醒 |
| drag | 按住移动 | 跟随 + 摆动 | 仅提醒 |
| land | 松手/甩出落地 | 400ms 弹跳回 idle | 提醒 |
| sleep | 无操作 5 分钟 | 慢速呼吸/睡姿 | 悬停、点击、priority≥2 |
| quiet | `pet.quiet` 或本地勿扰 | 低幅动作，不出气泡 | priority 3 |
| offline | 断连 | 降饱和 + 头顶小云朵 | 重连 |
| hidden | 全屏/锁屏/托盘隐藏 | 暂停渲染 | 退出隐藏 |

优先级：`drag(100) > 提醒(90) > talk(60) > react(40) > think(30) > idle(10)`。
`pet.act` 的 `interrupt=true` 才允许打断 talk/react；`priority=3` 无视 quiet 与 hidden。

服务端语义映射（客户端维护映射表，服务端不感知片段名）：

- `emotion` → 表情层/眼神偏移
- `action` → 片段组：`idle/wave/nod/shake/headpat/eat/sleep/think/celebrate/peek/hide`
- 未知 action → idle，不报错

## 8. 在场、免打扰与提醒

- 系统空闲 ≥60s 上报 `presence=idle`；恢复输入上报 `active`
- 锁屏 → 隐藏窗口并上报 `locked`
- 前台窗口铺满显示器且无任务栏 → 隐藏并上报 `fullscreen`；退出全屏 1s 内恢复
- 屏幕共享 / OBS：v1 由托盘手动「共享中」开关上报 `screen_share`；v2 再做进程自动识别
- 勿扰（本地）：不出气泡、不出声，`priority=3` 仍然显示但不抢焦点
- 提醒（`priority=3`）在全屏/隐藏态下用屏幕右上角小卡片呈现 6s，不激活窗口

## 9. 配对与异常态

- 首次启动：角色呈"休眠"灰调，头顶一张配对卡片，6 位数字框输入即自动提交
- 配对码来源沿用服务端规则：仅在已验证主人 QQ 私聊生成，5 分钟有效
- 成功：唤醒动画 + 一句问候；失败：卡片抖动 + 行内错误，不弹系统对话框
- 被吊销：卡片说明原因，只保留「重新配对」与「退出」
- 断连：头顶小云朵，悬停提示「未连接，点击重试」；点击立即重连，不打开浏览器
- 协议不匹配：设置页给出当前/所需版本，不自动更新

## 10. 多屏、缩放与性能

- 坐标按物理像素存储；DPI 变化时重新夹取到工作区
- 拖到副屏后记住该屏锚点，重启仍在副屏
- 缩放 50%–200%，Ctrl+滚轮步进 10%
- 隐藏/被遮挡时暂停动画；笔记本电池模式降到 12fps 并关闭眼神跟随
- 目标：空闲 CPU <3%、常驻内存 <200MB、冷启动 <3s

## 11. 视觉基调

- 深海色系：底色 `#0B1B2B`，强调 `#7FD8D3`，气泡白 95%
- 气泡：圆角 14px，1px 边框 `rgba(0,0,0,.08)`，阴影 `0 6px 20px rgba(0,0,0,.12)`
- 正文 14px / 行高 1.5 / `#1E2A33`，字体 Microsoft YaHei UI（不引入自定义字体）
- 菜单与卡片同一套玻璃样式；不做花哨粒子特效

## 12. 与协议 v1 的映射

| UI 动作 | 上行 | 下行 |
|---|---|---|
| 单击/双击 | `event.interaction(poke)` | `pet.act` / `pet.say` |
| 长按摸头 | `event.interaction(pet)` | `pet.act` |
| 拖动结束 | `event.interaction(drag)` | 可选 `pet.move` 回位 |
| 甩出 | `event.interaction(throw)` | `pet.act` |
| 换形象 | `event.interaction(figure)` | `pet.figure` |
| 发送文字 | `event.text` | `pet.say` |
| 发送语音 | `event.voice` 或本地 ASR 后的 `event.text` | `pet.say` |
| 焦点/全屏/锁屏变化 | `event.presence` | 披露等级在服务端生效 |
| 收到消息 | `ack(rendered/failed)` | — |
| 气泡撤回 | — | `recall` |

v1 待补的两项（先按本地行为实现，不阻塞）：

1. **选项气泡**：需要 `pet.ask` 下行与 `event.answer` 上行
2. **勿扰状态**：`presence` 枚举目前没有 `dnd`，v1 先做纯本地勿扰，服务端 `pet.quiet` 照常生效

## 13. MVP 边界

- P0：透明穿透、拖拽、戳、气泡、文字胶囊、托盘显隐、配对、idle/think/talk/offline、全屏隐藏
- P1：右键菜单与形象、缩放与锚点记忆、勿扰、提醒优先级、在场上报、多屏
- P2：语音输入、TTS、选项气泡、服装、情绪驱动的闲时选择

## 14. 验收口径

- 桌面图标、任务栏、其他窗口在角色空白处均可正常点击
- 胶囊展开时可正常输入中文（含 IME），Esc 后原应用立即获得焦点
- 全屏游戏 2s 内隐藏，退出后 1s 内恢复且不抢焦点
- 断网 5 分钟重连，不出现重复气泡、不丢已发送文本
- 连续 6 个气泡按序播放，不叠气泡
- 拔掉副屏后角色回到主屏且缩放不变
- 空闲 CPU <3%、内存 <200MB

## 15. 明确不做

- 常驻聊天窗口、聊天记录页、消息列表
- 任务栏缩略图、可见窗口边框
- 自动追逐鼠标、自动贴边吸附
- 主动截屏/读屏/键鼠注入
- 服务器主动拨入本机
